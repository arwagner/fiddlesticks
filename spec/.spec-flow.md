# Fiddlesticks spec-flow workspace

Per-feature `spec.md` files are the **source of truth**. The following are GENERATED and
git-ignored — never hand-edit them:

- `product.md` — run `node scripts/assemble.mjs`
- `dashboard.md` — run `node scripts/dashboard.mjs`
- `view.html` — run `node scripts/view.mjs`
- `analyze-product.md`, `features/*/analyze.md` — written by the `analyze` skill

`constitution.md` and `product-global.md` are **main-branch-only** — change them through a
dedicated PR, never inside a feature branch (editing either restages every feature's analyze gate).

Start a new feature with `/spec-flow:feature`, or run the guided `/spec-flow:flow`.

This workspace was bootstrapped from existing code via `/spec-flow:adopt` — the seeded specs
describe the system **as built** and start at `spec: draft`.
